# Semantic HTML5 & Accessibility Notes

- `header` contains branding and primary navigation.
- `aside` contains secondary navigation.
- `main` contains unique page content.
- `section` groups related features.
- `article` represents summary cards.
- `footer` contains site-level footer information.
- Forms use explicit labels, `fieldset`, `legend`, and `aria-describedby`.
- Tables use captions and `scope` on headers.
- Native `dialog` provides modal semantics and Escape support.
- Skip link provides bypass navigation.
- Visible focus styles support keyboard users.
- `aria-live` communicates search result updates.
