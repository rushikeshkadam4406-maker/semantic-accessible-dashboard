# Manual Accessibility Test

- [ ] Skip link appears when focused.
- [ ] All interactive controls are reachable with Tab.
- [ ] Focus indicator is visible.
- [ ] Navigation works without a mouse.
- [ ] Form works using keyboard.
- [ ] Search/filter results update.
- [ ] Dialog opens from a button.
- [ ] Dialog closes with its close button.
- [ ] Dialog closes with Escape.
- [ ] Table headers are correctly structured.

Also complete the W3C validation checklist in `docs/validation-checklist.md`.
