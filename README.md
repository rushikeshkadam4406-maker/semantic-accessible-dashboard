# Task 2 — Semantic HTML5 & Accessible Component Architecture

Accessible multi-page enterprise dashboard foundation using semantic HTML5 and WCAG 2.1-oriented patterns.

## Pages
- `client/index.html` — dashboard overview
- `client/services.html` — accessible service table and search/filter form

## Local setup
No build tool is required. Extract the ZIP, open the folder in VS Code, then open `client/index.html` with Live Server or a browser.

## Validation
Validate every HTML file with the W3C Markup Validation Service:
https://validator.w3.org/

Target: 0 errors. See `docs/validation-checklist.md`.

## Accessibility
Skip link, semantic landmarks, explicit labels, fieldset/legend, live status, scoped table headers, native dialog, visible focus styles, keyboard support, and reduced-motion support are included.
